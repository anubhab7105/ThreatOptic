# Technical Specification

## Overview
The AI-Powered Email Threat Detection, GeoLocation and Forensic Intelligence Platform leverages advanced AI/ML models, deep header parsing, and graph-based correlation to provide real-time email threat detection and extensive forensic capabilities.

## Tech Stack (as built in this checkout)
- **Backend Services:** Python 3.11+ + FastAPI (`backend/app/main.py`) for core logic and ML serving. No Django/Node service exists.
- **AI/ML Engine:** scikit-learn TF-IDF + LogisticRegression text classifier (active, 30% of fraud score via `modules/correlation/scoring.py:WEIGHTS`) plus rule-based urgency/impersonation/BEC cues (`modules/nlp/`), plus a lexical URL classifier (`modules/threat_intel/url_ml.py` → `ml_models/url_phishing_model.pkl`). PyTorch / HuggingFace Transformers are roadmap-only: a dormant `TRANSFORMERS_MODEL` + `TRANSFORMERS_REVISION` hook exists in `modules/nlp/engine.py`, but those libraries are not installed, no transformer runs, and production refuses unpinned models (falls back to sklearn).
- **Databases:**
  - **Relational:** PostgreSQL via Supabase Transaction Pooler (`DATABASE_URL`, `?pgbouncer=true` stripped for psycopg2). Models in `backend/app/models.py`; Alembic chain `834dc871451e → b7c2d1a9e4f5` auto-runs at boot. SQLite exists **only** as the pytest escape hatch (`TEST_DATABASE_URL`, `tests/conftest.py`); the app has no SQLite fallback and fails closed without `DATABASE_URL`.
  - **Document/Search:** Elasticsearch optional (`ELASTICSEARCH_URL/USER/PASSWORD`, `xpack.security.enabled=true`); when unset, `GET /api/v1/search` transparently falls back to SQLite `LIKE` over masked fields (`modules/search/elastic_sync.py` mirrors each analyzed email best-effort). No MongoDB in this checkout.
  - **Graph:** Neo4j optional (`NEO4J_URI/USER/PASSWORD`); when unset, `modules/graph/store.py` uses networkx in-process. `EXPECTED_REPLICAS>1` requires Neo4j or replicas diverge.
- **Frontend:** React 18 + TypeScript + react-router-dom 7 + `@supabase/supabase-js` (`frontend/package.json`), Vite 6 (`frontend/vite.config.ts`, `envDir: '..'` so the SPA reads the repo-root `.env`; only `VITE_*` reaches the browser). No D3.js/Cytoscape.js in this checkout — Geo uses an OSM iframe embed + links, graph uses a custom `GraphSvg` component (`frontend/src/pages.tsx`, `components.tsx`). Light "Inkwise" theme is default with a dark-SOC toggle (`theme.css`, `main.tsx:ThemeToggle`).
- **Infrastructure:** Docker (`backend/Dockerfile` multi-stage non-root, `frontend/Dockerfile` + `nginx.conf` with CSP/HSTS), `docker-compose.yml` (backend + frontend + neo4j + elasticsearch + kafka; **no local postgres** — Supabase), `k8s/backend.yaml` + `secret.yaml.example`, `railway.json` (backend) / `vercel.json` (frontend rewrites). Event path: bounded in-memory queue is primary (`modules/ingestion/queue.py`, `SMTP_QUEUE_MAX` count + bytes, overflow 452); Kafka (`KAFKA_BOOTSTRAP`) is an opt-in **mirror** for external consumers only; Celery (`CELERY_BROKER_URL`, `services/tasks.py`) is the opt-in async ingest path (`?async_mode` + `GET /tasks/{id}`); Redis (`REDIS_URL`) is the opt-in shared cache (else in-process dict, same TTLs). No RabbitMQ in this checkout.
- **Auth:** Supabase Auth owns sessions (email confirm + JWT). Backend verifies via JWKS/HS256 (`routers/deps.py`), reads role/org from `public.users` (trigger `supabase_handle_new_user.sql`). Only `GET /auth/me` exists — no local register/login/refresh routes, no `refresh_tokens` table (dropped by `b7c2d1a9e4f5`).
- **CI:** `.github/workflows/ci.yml` — backend (`ruff check backend --select E9,F`, `pip-audit`, `train_nlp.py`, `PYTHONPATH=backend pytest backend/tests`, Python 3.12) + frontend (`npm run lint`, `npm audit --omit=dev --audit-level=high`, `npm test`, `npm run build`, Node 22).

## Core Modules

### 1. Ingestion & Preprocessing
- **APIs & Protocols:** REST ingest (`POST /api/v1/emails/ingest` + `?async_mode` Celery path), `.eml/.txt/.mime` upload (`POST /api/v1/emails/upload`, 5 MB cap), personal Gmail OAuth2 (`routers/gmail.py`: status/auth-url/callback/sync/disconnect), org Google/Microsoft OAuth2 (`routers/oauth.py`: authorize/callback/status/sync-now/disconnect, server-side opaque state + PKCE S256 + redirect allowlist), inline SMTP relay (`SMTP_ENABLED=1`, `modules/ingestion/smtp_server.py` + bounded `queue.py` + lifespan consumer in `main.py`), background mailbox polling (`services/mailbox_poll.py`, `MAIL_POLL_MINUTES`, 0 = manual Sync now). No IMAP listener in this checkout; Microsoft Graph / Google Workspace are reached via the OAuth connectors above.
- **Parsing Engine:** `modules/ingestion/parser.py` — robust MIME parsing, raw-header extraction, body text + 8-byte-magic attachment metadata; `bleach` sanitization with size/count caps; ingest is idempotent per tenant on `(raw_eml_hash, organization_id)`; `MAX_RAW_BYTES` 5 MB.

### 2. Header Forensics & Traceability
- **Header Analysis:** `modules/forensics/header_parser.py` (brand spoof, multi-From, homoglyph fold), `received_chain.py` (validated IPv4/IPv6, folding fix, registrable-domain compare, routing-anomaly flags), `auth_validator.py` (envelope sender, real DMARC alignment, distinct `unverifiable` offline status — never loopback-substituted).
- **Authentication Validation:** SPF / DKIM (`dkimpy`) / DMARC / ARC alignment checks in `auth_validator.py`; offline (`ENABLE_LIVE_LOOKUPS=0`) reports `unverifiable` and scores near-zero rather than failing.
- **IP & Geo Engine:** `modules/traceability/ip_extractor.py` (trust boundary `TRUSTED_RELAY_HOSTS/IPS`, last-external-hop origin), `geoip.py` (MaxMind GeoLite2-City.mmdb + HTTPS ip-api fallback + offline stub, 45/min throttle, 24h cache), `whois_dns.py` (python-whois + dnspython, 24h/1h caches, no global-timeout side effects), `vpn_tor.py` (Tor bulk list + fixed DNSEL form, VPN heuristics). No IP2Location in this checkout.

### 3. ML & NLP Engine
- **Text Analysis:** TF-IDF + LogisticRegression (`ml_models/phishing_clf.joblib`, trained by `scripts/train_nlp.py` from `fetch_datasets.py` SpamAssassin + curated BEC → `ml_models/dataset.csv`, gitignored; 80/20 stratified split, metrics → `metrics.json`, served by `GET /api/v1/model/metrics` + Model Info page) fused with linguistic cues (urgency/impersonation/BEC/payment language); transformer rerank is dev-only/opt-in (`TRANSFORMERS_MODEL` + pinned 40-char `TRANSFORMERS_REVISION`, production falls back to sklearn when unpinned).
- **Link/Attachment Analysis:** `threat_intel/url_analyzer.py` (extract/defang, lexical `url_ml.py` classifier) + `threat_intel/feeds.py` (VirusTotal submit→poll with cap, URLhaus, MISP, DNSBL, Spamhaus DROP, operator `backend/data/local_blocklist.txt`, dev-only demo fixtures) + `threat_intel/attachment_analyzer.py` (VT hash + macro/double-ext/exec/magic-mismatch heuristics, `attachment_risk` weight 0.10). No attachment sandbox in this checkout.
- **Model trust:** artifacts carry `.sha256` sidecars (verified at load; `modules/model_trust.py`); production can pin `MODEL_VERIFY_KEY` (Ed25519) and refuses to unpickle otherwise (never set `MODEL_TRUST_INSECURE=1` outside local dev); `scripts/sign_model.py` keygen/signs offline.

### 4. Correlation & Attribution
- **Graph Construction:** `modules/graph/store.py` — `upsert_email_graph` per analyzed mail (`Email_Address -SENT_FROM→ IP_Address -HOSTS→ Domain -PART_OF→ Threat_Campaign`); Neo4j-first reads (`find_campaigns`, `related_entities`) with networkx fallback; driver closed on shutdown; `/graph/campaigns` returns infra clusters only (no tenant PII), `/graph/related` is tenant-filtered.
- **Scoring System:** `modules/correlation/scoring.py` weighted ensemble — nlp 0.30 / auth 0.25 / intel 0.20 / routing 0.15 / attachment 0.10 (sums to 1.0); `score_breakdown[]` (`signal_name/weight/value/contribution_to_score`) sums exactly to `fraud_score` (asserted by `scripts/live_demo_check.py`); behavioral rules: new-domain(<30d)+payment +30, SPF/DKIM-fail + exec-impersonation forces High (≥75); policy bands Critical ≥90 Quarantine / High ≥75 JunkOrHold / Medium ≥50 DeliverWithBanner / Low Deliver (`modules/alerting/dispatcher.py:evaluate_policy`).
- **Privacy/retention/reporting:** `modules/privacy/masking.py` (unconditional, no unmask bypass), `retention.py` (batched deletes + per-batch rollback, daily 03:00 `services/scheduler.py`), `reporting/generator.py` + `privacy/chain_of_custody.py` (SHA-256 + HMAC manifest v1, `CUSTODY_KEY` + `CUSTODY_KEY_PREVIOUS` rotation).

## Integrations (implemented vs roadmap)
- Implemented: VirusTotal (URL + attachment hash), URLhaus, MISP (`MISP_URL/KEY`), DNSBL/Spamhaus DROP, Slack webhook + PagerDuty routing key (dedup/rate-limit/backoff in `alerting/dispatcher.py`), Gmail + Microsoft Graph OAuth connectors, MaxMind/ip-api geo, WHOIS/DNS.
- Roadmap-only (no code in this checkout): OTX AlienVault, SIEM/SOAR (Splunk/QRadar/Cortex XSOAR), ticketing (Jira/ServiceNow), attachment sandbox detonation.
